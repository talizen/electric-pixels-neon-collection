# Electric Pixels — Neon Particle Collection

A neon particle showcase: eight silhouettes made of glowing square pixels in a radial neon gradient. The pixels drift and flicker, scatter away from the cursor and snap back elastically. Browse them in a grid, open a full-screen hero or a live stage, and restyle everything with four neon palettes.
